# Business-Insights-360-Power-BI
Business Insights 360 is an end-to-end Business Intelligence project developed using Power BI to provide a consolidated view of business performance across Finance, Sales, Marketing, Supply Chain, and Executive functions.

The project combines data sourced from SQL and Excel, followed by data transformation, modeling, DAX-based calculations, and interactive visualization in Power BI.

🛠️ Tools & Technologies
Power BI
SQL
Excel
Power Query
DAX
Data Modeling
Data Transformation
Data Visualization

🔄 Project Workflow
SQL + Excel → Power Query → Data Transformation → Data Modeling → DAX Measures → Power BI Dashboards → Business Insights

📊 Dashboard Modules
Finance View — Net Sales, Gross Margin, Net Profit, P&L analysis and financial performance
Sales View — Sales performance, customer/product analysis and trends
Marketing View — Marketing performance and business metrics
Supply Chain View — Operational and supply-chain performance analysis
Executive View — High-level KPIs and consolidated business performance
